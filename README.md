# Премия года КМБП — бот + мини-апп на Telegram Serverless

## Запуск (10 минут)

1. @BotFather → ваш бот → **Serverless** → включить. Там же возьмите **CLI Access token**.
2. Откройте `tgcloud/lib/config.js` и впишите свой Telegram ID в `OWNER_IDS`.
3. В папке проекта:
   ```bash
   npm install
   npx tgcloud login      # вставить CLI-токен
   npx tgcloud push       # зальёт код и мини-апп, напечатает адрес https://app<ID>.tgcloud.ai/
   npx tgcloud migrate    # создаст таблицы (safe-изменения — подтвердить)
   ```
4. В @BotFather → Bot Settings → Configure Mini App / Main Mini App укажите этот адрес.
5. Впишите адрес в `APP_URL` (config.js) и сделайте `push` ещё раз — или задайте его в боте: Админка → Настройки → URL мини-аппа.
6. Создайте группу владельцев, добавьте туда бота и отправьте `/setchat` — сюда будут приходить заявки.
7. Напишите боту `/admin`.

> Премиум-эмодзи на кнопках и в тексте работают, если у **владельца бота** есть Telegram Premium.
> Если нет — бот автоматически отправит сообщения без них (обычные эмодзи, обычные кнопки).

## Баннер
Админка → **Баннер**: отдельно для бота и отдельно для сайта (мини-аппа). Нажмите «Загрузить фото» и пришлите картинку как обычное фото. Можно вернуть стандартный (`app/img/hero*.jpg`) или убрать баннер совсем. Изменения применяются сразу, без повторного `push`.

Для сайта фото скачивается и хранится в базе, оно не попадает в выгрузку базы (при необходимости его можно загрузить заново).

## Спонсоры
В админке откройте **Спонсоры**:
- добавьте Telegram username спонсора (он должен открыть бота/мини-апп именно из этого аккаунта);
- включайте и закрывайте приём в отдельных подноминациях **Личность**, **Бот**, **Проект**;
- добавляйте баннер: HTTPS-ссылка и фото (подписи нет — в мини-аппе показывается только кликабельная картинка). Для ссылки «Поддержать нас» есть готовая кнопка (DonationAlerts, `DONATE_URL` в `config.js`);
- обычные пользователи голосуют как раньше. Если юзернейм в обычной номинации (Бот / Проект / Личность) точно совпал с записью спонсора в подноминации того же типа, заявка остаётся в обычной номинации, но помечается как голос в спонсорскую: пользователю пишется «Ваш голос ушёл в спонсорскую номинацию», в карточке заявки и в разделе «Спонсоры» админки видны отметка и счётчик голосов. Добавлять кандидатов в спонсорские номинации по-прежнему могут только спонсоры;
- при подаче спонсорской заявки все прежние записи с тем же username кандидата копируются в неё для организаторов. Исходные записи остаются без изменений.

После обновления кода сначала сделайте резервную копию в админке, затем примените новую схему (добавилась колонка `applications.sponsor_nomination_id`) и отправьте код:
```bash
npx tgcloud migrate
npx tgcloud push
```
Файлы изображений баннеров не включаются в выгрузку базы; после восстановления их нужно загрузить снова.

## Поиск и удаление заявок
Админка → **Заявки** → **Найти по юзернейму**. Точный username кандидата показывается первым; если точного совпадения нет, доступен поиск по части имени. У каждой найденной заявки отдельная кнопка удаления и подтверждение: остальные заявки с тем же username останутся в базе.

## Структура
- `tgcloud/schema.js` — таблицы · `tgcloud/handlers` — обновления бота · `tgcloud/endpoints` — функции мини-аппа · `tgcloud/lib` — общий код
- `app/` — мини-апп (чистый HTML/CSS/JS, без сборки). Вне Telegram страница показывает только заглушку «Откройте в Telegram» — данных и демо-контента там нет
- `test/` — проверки логики на моке SDK: `cd test && npm i && node --no-warnings --import ./register.mjs run.mjs`

## Важно
- В Serverless нет планировщика (cron), поэтому ежедневная выгрузка базы запускается «лениво»: при первой активности в боте или мини-аппе после того, как прошли сутки.
- Рассылка идёт пачками; если Telegram просит притормозить — в боте появится кнопка «Продолжить».
- Новости: премиум-эмодзи в мини-аппе не показываются (по ТЗ — без эмодзи), остальное форматирование — да.
